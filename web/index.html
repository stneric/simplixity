What are you researching?

Simplixity searches the web, reads the pages it finds, and cites what it used.

    Simplixity can be wrong. Verify anything that matters.

    Settings

    Writes the answer, and does the planning and reading behind it. Everything below can be left alone; this is the one that decides how good an answer is.

    A small, fast model for the cheap calls: triage, the gap check and the citation check. It decides how much searching a question is worth and is the one call standing between you and the first word of the answer. Off means the chat model does these too, which is correct and costs more.

    Checks every cited sentence against the source it cites, once the answer is written. Pick one from another model family than the chat model: a model judging its own answer shares the blind spots that wrote it. Off, the router checks web answers and the writing model checks its own in literature projects. The footer of every answer says which model checked it.

    Ranks retrieved passages before they reach the model. Charged per source ranked rather than per call, so a deep run spends far more tokens here than on the models, which is why the footer counts the two separately. Turn it off and Simplixity falls back to keyword ranking: slightly worse, never broken.

    Names a new chat in a few words instead of using the first line of the question. One short call per new chat, and it runs after the answer is finished. It is not in the price the footer reports, which is written before this call happens, so anything it spends is spent invisibly. Off by default for that reason; on, pick the cheapest model you have.

    Each run can override this from the composer. Depth sets how wide the search goes, how many pages are read, and when the run stops regardless.

    Which corpora searches draw on. Results from every selected corpus are ranked against each other, and each source is labelled with what it is: official text, a paper, documentation, a newsroom or an ordinary page.

    Where “what is the weather” means, when the question does not say. Simplixity never asks the browser for your location (geolocation is switched off for this page), so this is the only place a default can come from. Left empty, a question without a place says so and searches instead of guessing.
